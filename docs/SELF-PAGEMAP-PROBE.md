# Guest-owned page metadata probe

This is a standalone Android executable, outside any game. It allocates one anonymous private page, touches it, opens only `/proc/self/status` and `/proc/self/pagemap`, reads the one pagemap entry for its own page, reports page-present and swapped flags and whether its guest PFN is nonzero, unmaps and checks the same entry. On open/read denial it reports the error and cleans up; it does not request privileges or weaken protections. If exposed, a PFN is a guest physical frame for this owned page, not a host physical address and not an arbitrary guest-to-host translation. A zero PFN is ambiguous (redaction or a real zero frame); unprivileged PFNs are commonly masked. It cannot read a game, obtain a game address, or demonstrate draw correlation. Synthetic parser tests and native Linux lifecycle tests run in CI; Android is cross-compiled for the x86-64 emulator shell. No host scanner is used.
