# Five-batch targeted marker probe

This is a separate, explicitly gated diagnostic built from corrected target probe 3f92660. It scans only committed MEM_PRIVATE + PAGE_READWRITE | PAGE_WRITECOMBINE (0x404), with a fresh guest-owned synthetic marker. It starts from the beginning for the new process/worker and allows up to five individually authorized 512 MiB attempted batches. It never resumes an old worker cursor or assumes that the earlier guest marker or addresses remain valid. A snapshot of ~2.23 GiB selected regions does not guarantee the live scan will finish within 2.5 GiB or that regions remain unchanged.

It uses arena-target5-marker-* control names, unique add-on name, and otherwise the same limits, exclusions, stop-on-match and three individually gated first-candidate baseline/rotate/free boolean checks. No raw host contents are logged. This test can internally read unrelated data and may affect performance or game enforcement. A match may be a copy; a miss does not prove the absence of a guest mapping. Permission is required before installation, restart and each batch. No changes to opengl32.dll, Secure Boot, or installed security protections. See TARGETED-GUEST-MARKER.md for design and test limitations.
